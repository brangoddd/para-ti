# Un sobrecito para ti ♡

Una sorpresa de Hello Kitty con una carta, cuatro recuerdos, un frasquito de mensajes y una melodía original. HTML, CSS y JavaScript, sin instalación ni compilación.

## Abrir

Abre `index.html` en un navegador o sirve esta carpeta con un servidor estático. Conserva juntos `index.html`, `style.css`, `app.js` y `assets/`.

## Personalizar para compartir

1. Abre la página y pulsa **Personalizar**, al pie.
2. Escribe el nombre, la firma y la carta. Puedes elegir hasta cuatro fotos.
3. **Guardar detalles** conserva los cambios solo en ese navegador.
4. Para que ella vea tus cambios, pulsa **Descargar página personalizada** y reemplaza `hello-kitty/index.html` en el repositorio con el archivo descargado. Las fotos se incluyen dentro del HTML.

Los textos y las imágenes que publiques en un repositorio público serán públicos.

También puedes modificar los valores de `base` y `defaultLetter` en `app.js`, o introducir un objeto JSON en el elemento `personal-data` de `index.html`, con `to`, `from`, `letter` y `photos`.

## GitHub Pages en el repositorio para-ti

Esta carpeta se publica en `https://brangoddd.github.io/para-ti/hello-kitty/` cuando GitHub Pages sirve la rama `main` desde `/ (root)`.

Si Pages aún no está habilitado: Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save. Espera a que termine el despliegue antes de compartir el enlace.

No requiere dependencias de Node ni un workflow adicional. No modifica el regalo que ya está en la raíz del repositorio.
